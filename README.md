# 🔐 Steganography

## 📌 Description

A **C-based Steganography project** that securely hides secret data inside a **BMP image** and extracts the hidden data when required. The project demonstrates how data can be concealed within an image using **Least Significant Bit (LSB) manipulation**.

## ✨ Features

* 🔒 Hide secret data inside a BMP image
* 🔓 Extract hidden data from a stego image
* 🖼️ Supports BMP image files
* 📄 Supports text files for secret data
* ⚙️ Uses bit-level operations for data hiding
* 💻 Implemented completely in C

## 🛠️ Technologies Used

* 💻 C Programming
* 🖼️ BMP File Handling
* 🔢 Bitwise Operations
* 📂 File Handling
* 👉 Pointers
* 🧠 Data Encoding & Decoding

## 🎯 Objective

To understand and implement **data hiding techniques** using image steganography and bit-level manipulation in C.

## 🚀 How It Works

### 🔐 Encoding

Secret data is embedded into the BMP image by modifying the **least significant bits (LSB)** of the image data.

### 🔓 Decoding

The hidden data is extracted from the modified image by reading the stored bits and reconstructing the original secret data.
